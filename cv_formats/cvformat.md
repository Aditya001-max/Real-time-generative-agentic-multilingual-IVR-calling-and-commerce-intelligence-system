## Real-Time Generative Agentic Multilingual IVR & Commerce Intelligence Platform
**Self Project · National Finalist, Gappy AI** · 2025–2026
**Role:** GenAI Engineer (solo build)

Production-grade **Agentic AI** platform that transforms traditional IVR into an autonomous multilingual **AI employee** for real-time voice + WhatsApp commerce — handling COD verification, RTO recovery, order tracking, returns, payments, product recommendations and human escalation across **9 Indian languages** with dynamic Hinglish / code-mixed conversation.

- **Engineered a LangGraph-based agent orchestration layer** with **15+ enterprise tools** (CRM, OMS, Product Search, Order Tracking, RTO, Knowledge Base, Ticketing, Customer History, Recommendation Engine, Courier APIs, WhatsApp, Payment Status, Escalation, Notification, Analytics), enabling autonomous reasoning, long-term customer memory, dynamic tool selection and policy-controlled execution.
- **Served Llama 3.3 70B via vLLM** with continuous batching + paged attention for high-throughput inference; applied **LoRA / QLoRA fine-tuning**, domain instruction tuning and prompt optimisation to specialise the LLM for Indian e-commerce conversations.
- **Built a hybrid multilingual RAG pipeline** using **BGE-M3 embeddings + Qdrant (vector) + OpenSearch (BM25)** over product catalogs, FAQs, return policies, shipping SOPs and business documents — grounding responses and cutting hallucinations on domain queries.
- **Delivered a sub-second real-time voice stack** with **Deepgram streaming STT + Coqui XTTS TTS**, barge-in / interruption handling, voice continuity across turns and mid-call language switching across 9 Indian languages.
- **Developed XGBoost / LightGBM models** for intent, sentiment, churn, RTO, fraud, CLV, segmentation, retry optimisation and personalised product ranking, trained on customer, transactional and conversational signals.
- **Built the backend in Python 3.12 / FastAPI** with **PostgreSQL, Redis, Kafka**, integrating **Twilio Voice, WhatsApp Cloud API, Shopify, Chatwoot and courier APIs**; deployed on **Docker + Kubernetes** with horizontal autoscaling.
- **Implemented full MLOps** with **MLflow (registry), Langfuse (LLM observability), Evidently AI (drift), Prometheus + Grafana (metrics)** — enabling continuous evaluation, drift detection and explainability.
- **Recognised as National Finalist, Gappy AI** for production-readiness and technical depth of the agentic AI stack.

**Stack:** Python 3.12 · FastAPI · LangGraph · Llama 3.3 70B (vLLM) · LoRA/QLoRA · BGE-M3 · Qdrant · OpenSearch · Deepgram · Coqui XTTS · XGBoost · LightGBM · PostgreSQL · Redis · Kafka · Docker · Kubernetes · MLflow · Langfuse · Evidently AI · Prometheus · Grafana · Twilio · WhatsApp Cloud API · Shopify · Chatwoot
